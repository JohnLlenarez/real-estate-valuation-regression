# real-estate-valuation-regression
A multi-variable regression study designed to identify significant drivers of real estate valuation. This project utilizes statistical regularisation to predict property values and assess the sensitivity of prices to regional and structural variables.

Methodology: Used Ordinary Least Squares (OLS) and Lasso/Ridge regression to minimize overfitting and identify key predictors.

Data Analysis: Conducted exploratory data analysis (EDA) to find correlations between property attributes and market premiums.

Application: Provides actionable insights into how variables like location and property age quantify investment risk.
